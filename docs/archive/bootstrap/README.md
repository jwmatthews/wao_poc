# Bootstrap documents

These documents were used by the coding agent to bootstrap the Workload
Availability Operator (WAO) proof of concept. They are retained here as historical
context for the project's original design, upstream research and implementation
plan.

| Document | Purpose |
| --- | --- |
| [Design brief](design-brief.md) | Original approach, decisions D1–D10 and non-goals |
| [Operand reference](operands.md) | Upstream component facts used during implementation |
| [Implementation plan](implementation-plan.md) | Original task-by-task plan and verification approach for the coding agent |

The documents preserve their original content apart from link updates. Status
statements, unchecked tasks, example code and commands reflect the bootstrap
stage and may differ from the current implementation. The implementation plan is
a historical record rather than a current task queue.

For current project status and usage, start with the [project README](../../../README.md).
See [AGENTS.md](../../../AGENTS.md) for repository instructions,
[release-set.yaml](../../../release-set.yaml) for the pinned upstream releases,
and the [cluster test README](../../../test/cluster/README.md) for the live-cluster
verification harness.
